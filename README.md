# The Critical Thinker's Journey™ Part 2: Exploring Ideas and Making Moves

## Candidate product baseline

Part 2 is the CTJ movement and experimentation product. Its verified 10-day curriculum covers testing arguments, evidence in action, correlation versus causation, decision paralysis, learning from failure, creative experiments, lateral action, adaptive mental models, actionable analogies, and breakthrough experiments.

The candidate preserves that substance while separating four core daily responses from optional deeper work.

## Run

Prerequisite: Node.js 22 or later.

```bash
npm install
npm run dev
```

Validation:

```bash
npm test
```

## Current architecture

- React, TypeScript, Vite
- 10 days, 2 checkpoints, 1 final reflection
- local browser persistence
- optional browser dictation
- deterministic local Thinking Partner prompts
- PDF, JSON, and TXT export
- responsive and accessibility controls
- no external AI API key
- no account or cloud backend in this candidate product-core baseline

## Source reconciliation

The candidate retains the substantive legacy Part 2 curriculum from the 2025 HTML source.

Material modernization decisions include:
- core versus optional deeper prompts to reduce daily overload
- Day 6 uses Creative Prototype instead of duplicating the Day 1 Tiny Experiment framework name
- action tips remain distinct from Part 1 logic tips
- runtime claims now match actual persistence and export behavior
